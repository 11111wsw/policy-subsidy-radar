# 补贴雷达 · 丽水企业政策匹配工具

> 录入企业画像，自动比对就业、创业、科技三类补贴政策，告诉企业**能领多少、还差什么、要准备哪些材料**。

- 在线演示：https://policy-subsidy-radar.vercel.app
- 演示路径：首页 →「先看演示效果」，或直接打开三家虚构演示企业的匹配结果，无需注册

## 背景

各级政府面向企业的补贴政策数量多、分散在不同部门文件中，且有明确的申报时限。大量中小企业（尤其小微企业）不知道自己符合哪些政策、错过申报窗口，只能依赖中介的信息差。

本产品把「政策条件」结构化，让企业用 2 分钟的问卷完成一次自助政策体检。

## 核心功能

1. **企业画像测评**：覆盖用工、社保、创业、研发与资质等关键信息，不确定的字段可留空
2. **政策匹配引擎**：每项申报条件独立核对，输出「可申报 / 有差距 / 待确认 / 不符合」，结论可解释、可复核
3. **匹配结果总览**：首年预计可领金额汇总、逐项政策卡片、差距补齐建议
4. **政策详情**：企业情况 vs 申报条件逐条对照表、材料清单、办理路径
5. **AI 申报建议**：结合政策与企业情况生成个性化申报建议

## 技术架构

- **Next.js（App Router）+ React + TypeScript + Tailwind CSS + shadcn/ui**
- **确定性规则引擎负责匹配**：政策条件建模为结构化规则，匹配结果由代码计算，保证金额与结论可核验、可审计
- **LLM 只承担「建议」角色**：AI 不参与政策匹配判断，避免凭空生成金额或条件；未配置模型 API Key 时系统使用预置建议，演示闭环完整
- 政策库与演示数据为静态数据，无需数据库即可运行

### 架构取舍

申报匹配要求结论稳定、可解释，因此规则判断不交给 LLM；LLM 的价值定位在自然语言交互与申报建议。金额估算统一为首年口径，多年期补贴仅计首年，税收优惠因取决于企业应纳税所得额而单独标注。

## 数据来源与免责声明

政策数据整理自丽水市及浙江省政府部门的公开文件（截至 2026 年 9 月），包括就业岗位补贴、一次性扩岗补助、失业保险稳岗返还、就业见习补贴、一次性创业补贴、创业带动就业补贴、研发费用加计扣除、科技型中小企业认定、研发投入财政奖补、专精特新培育等。

政策具有时效性与地域差异（部分奖励标准以区县口径为例），申报条件与补贴金额请以主管部门最新公告为准。三家演示企业及全部数据均为虚构，不涉及任何真实企业信息。

## 本地运行

```bash
npm install
npm run dev
# 打开 http://localhost:3000
```

可选：配置环境变量 `DEEPSEEK_API_KEY` 后，AI 申报建议由大模型实时生成；未配置时使用预置建议。
